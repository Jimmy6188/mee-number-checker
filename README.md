# MEE 多国语数字校对工具

自动检查多国语 PDF 译文中数字与英文原稿是否一致的校对工具。基于客户指示原稿（红框 + 青色高亮）锚定校对对象，精确捕获框内数字错误，忽略框外内容。

## 功能

- **锚定模式**：以客户指示原稿（红框 Square 批注）为校对对象，只查红框内数字
- **多国语**：支持德/法/荷/西/意/希/葡/保/波/捷/斯/匈/斯洛文/罗/克/塞/乌等 17+ 语言
- **数字归一化**：处理欧式小数（点/逗号）、千分位、单位上标（²/³）等写法差异
- **聚合差异识别**：译文聚合/拆散、数字串级联连写、区域成组等排版差异自动识别
- **跨语言交叉验证**：同检查点多语言同类聚合自动判为一致（排版差异）
- **四档风险分级**：一致（绿）/ 低风险（蓝，大位移确认）/ 中风险（黄，需复核）/ 高风险（红，必须处理）

## 输出

- `数字校对报告.xlsx`：汇总 / 明细 / 语言矩阵 / 说明 四页
- `数字校对报告.html`：查错工作台，筛选按钮按风险颜色显示，双方截图内嵌可点击
- `复核PDF\`：问题项在译文/英文稿上的定位批注
- `snaps\`：问题项双方截图
- 输出目录：`<数据目录>\_校对结果\`

## 使用

### GUI（推荐，Windows 免装 Python）

双击 `MEE数字校对.exe`（或运行 `mee_checker_gui.py`），依次选择：
1. 英文指示稿（红字标注版）PDF
2. 客户锚定指示原稿（可选，提供则启用锚定模式）
3. 多国语 PDF 文件夹

点击"开始校对"，完成后自动打开报告。

### 命令行

```bash
python mee_checker.py --base "英文红字指示稿.pdf" --anchor "EN-高光指示原稿.pdf" --dir "多国语文件夹"
```

- `--base`：英文红字指示稿（必填）
- `--anchor`：客户高光指示原稿（可选，红框+青色高亮）
- `--dir`：多国语 PDF 文件夹（必填）
- `--out`：输出目录（默认 `<dir>/_校对结果`）

### bat 拖放

将 英文指示稿 / 多国语文件夹 / 锚定原稿 依次拖到 `运行校对.bat` 上（后两个可选）。

## 状态体系（四档风险）

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 一致 | 绿 | 匹配且数值等价，无风险 |
| 低风险 | 蓝 | 大位移确认：值相同但位置大幅移动，抽查项 |
| 中风险 | 黄 | 无法确认对应（串位/聚合/图内/跨页位移），建议人工核对 |
| 高风险 | 红 | 数值不同（真差异）或值完全不存在（真缺失/多余），必须处理 |

判定保守原则：不确定不判一致；值确认不同 → 高风险；值存在但仅此证据 → 中风险；值完全不存在且无剩余候选 → 高风险。

## 依赖

- Python 3.10+
- PyMuPDF (fitz)、openpyxl（GUI 版仅标准库 tkinter）
- 无 scipy/numpy 依赖（匈牙利算法为纯 Python 实现）

## 打包（可选）

```bash
python -m PyInstaller --onedir --windowed --name "MEE数字校对" \
  --exclude-module scipy --exclude-module pandas --exclude-module PIL \
  --exclude-module numpy --exclude-module lxml --exclude-module cryptography \
  mee_checker_gui.py
```

产物约 68MB / zip 约 31MB，同事解压即用。
